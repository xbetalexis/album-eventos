# Álbum de eventos

Web estática para GitHub + Vercel que redirige a álbumes compartidos de Google Fotos.

## Editar el evento
Abrí `eventos.js` y cambiá:
- nombre
- fecha
- mensaje
- link de Google Fotos
- imagen de fondo

## Agregar una foto de fondo
Guardala en `fondos/`, por ejemplo:
`fondos/sophia.jpg`

## URL final
Con Vercel, el evento se verá así:
`https://TU-PROYECTO.vercel.app/e/sophia-xv`

Ese es el link que conviene convertir en QR.
